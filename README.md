# 菊とレモン

刺身工場のライン。流れてくるディルドには菊を、アワビにはレモンを。真下に来た瞬間に押す。1回まちがえたらライン停止。こなした数で競う。

遊ぶ：https://nasubi-no-oniwa.github.io/kiku-lemon/

- `index.html` … ゲーム本体
- `sim.js` … 流れてくる物の並びと、記録の確かめ（ゲームと記録の確認で同じものを使う）。並びを変えるときは `V` を上げること（昔の記録の計算が合わなくなるため）
- `database.rules.kl.json` … ランキングのルール。GitHub に上げると自動で ft-green の `kl` に反映（ほかのゲームのルールはそのまま）
- `kl-remove.txt` … 消したい記録のIDを1行ずつ書いて上げると、その記録を消す
- 記録の確認は10分ごとに自動で動き、計算が合わない記録・機械で押したような記録を消す
